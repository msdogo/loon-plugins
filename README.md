# Loon PCDN 屏蔽插件

通过 Loon 规则屏蔽国内主流视频、音乐平台的 **PCDN 上传加速域名**，避免客户端在后台偷偷占用你的上行带宽。

规则整理自 B 站专栏：[路由器自定义 hosts 屏蔽 PCDN 域名清单](https://www.bilibili.com/opus/1138105448036040737)。

## 屏蔽原理

各平台的 PCDN 客户端会主动连接带 `hcdn` / `pcdn` / `trackercdn` / `atm` 等特征的域名，把本地缓存的视频、音频分片上传给其他用户（即所谓"做种"）。本插件用 `REJECT` 规则拦截这些纯上传通道，同时**不触碰**真正用于播放的 CDN 域名，因此正常观看、收听不受影响。

## 覆盖平台

| 平台 | 说明 |
| --- | --- |
| 腾讯视频 | 仅拦上传加速域，保留播放必需域 |
| 爱奇艺 | 仅拦 PCDN 上传域 |
| 优酷 / 土豆 | 仅拦 `atm.youku.com` 系列上传域 |
| 哔哩哔哩 | `mcdn` 即 PCDN 上传节点 |
| 西瓜视频 / 抖音 / 斗鱼 | 推拉流与 P2P 域名 |
| 酷狗音乐 | trackercdn 上传加速 |
| 网易云音乐 | 163jiasu 加速、sf.163 上传 |
| QQ 音乐 | P2P 加速节点 |
| 通用 | `p-cdn.com`、`pscdn.co`、`p.scdn.co` |

此外还包含腾讯广点通 `gdt.qq.com`、腾讯视频统计 `cm.l.qq.com` 两条广告/埋点域名，如不需要可自行删除。

## 安装

任选一种：

1. **URL 导入**：Loon → 配置 → 插件 → 右上角 `+` → 填入本仓库 raw 地址  
   `https://raw.githubusercontent.com/msdogo/loon-pcdn-block/main/PCDN-Block.plugin`
2. **本地导入**：下载 `PCDN-Block.plugin`，传到手机后在 Loon 中「从文件导入」。

导入后在「插件」页启用即可，规则随配置下发，无需打开 MITM。

## 注意事项

- `d.kugou.com`、`sf.163.com` 域名较宽泛，若酷狗歌单或网易云评论加载异常，删除对应行。
- 末尾两行 `DOMAIN-KEYWORD,pcdn/mcdn` 默认注释。关键字规则范围大、容易误杀播放域名；想更激进拦截时可取消注释，但需自行验证各平台播放。
- PCDN 域名会不断变化，建议每季度复查一次。
- 若某平台播放异常，先禁用本插件确认是否本插件导致，再定位到具体分组删除。

## 验证

- 用 Loon 的「日志」页过滤 `pcdn`/`mcdn`，应能看到 REJECT 记录。
- 观察路由器或系统监控中的上行带宽，正常观看时上行应接近 0。
